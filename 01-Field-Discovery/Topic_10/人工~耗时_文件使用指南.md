# 人工和AI批量随机生成用户密码耗时 — 使用指南

## 一、环境准备

依赖库安装（仅需一次）：

py -m pip install openpyxl

验证：

py -c "import openpyxl; print(openpyxl.__version__)"

## 二、文件清单

| 文件 | 说明 |
|---|---|
| 人工和AI批量随机生成用户密码耗时.py | 主程序 |
| 人工和AI批量随机生成用户密码耗时.bat | 双击启动器 |

两个文件放在同一目录。

## 三、运行方式

方式一（推荐）：双击 人工和AI批量随机生成用户密码耗时.bat

方式二（排错用）：在 cmd 中手动运行：

cd /d D:\liujunhao.Github\ICEC-2026-0140-liujunhao\01-Field-Discovery\Topic_10
py 人工和AI批量随机生成用户密码耗时.py

## 四、操作流程

1. 输入密码数量（默认 10，直接回车）
2. 是否对比（默认 y，直接回车）
3. 按回车开始计时，逐个输入「账号 + 密码」：
   - 账号：纯英文字母
   - 密码：12 位，必须含大写、小写、数字
   - 不合法会提示并让你重新输入
   - 输完 N 组自动停止计时
4. AI 自动生成同样数量的账号密码（固定 user01 编号）
5. 显示耗时对比
6. 询问是否导出 Excel（默认 y），可直接回车存当前目录
7. 生成 人工和AI批量随机生成用户密码耗时.xlsx

## 五、常见问题

| 问题 | 解决 |
|---|---|
| can't open file ... No such file or directory | 先 cd /d 到脚本所在目录再运行 |
| 提速比报错 ZeroDivisionError | 本地代码是旧版，用最新代码覆盖 .py 文件 |
| Excel 没生成 | 确认第 6 步选了 y，且目录存在 |
| 密码反复提示重输 | 检查密码是否正好 12 位、含大小写+数字 |

- 密码为实验数据，不要用于真实账号，用完建议删除表格
- 第一次运行前确认 .py 已是最新版本，避免旧代码除零报错
