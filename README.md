## 第二阶段：项目三

本阶段以电风扇为对象，用手机麦克风采集声信号，做转码、FFT特征、规则分类。

工况与采集：一档、二档、三档为正常；卡入异物、进风口堵住为异常。每工况3次，共15段m4a。采样率44100Hz，单声道转码，手机距风扇约10cm，每段约15秒。采集记录见 process_logs/采集记录.csv，标签见 data/label_map.csv。

转码：iterations/v1_录音转wav.py 用 pydub+FFmpeg 将 m4a 转为44100Hz、单声道、16bit PCM wav，输出到 data/processed。

特征：iterations/v2_fft特征提取.py 对wav做FFT，提取采样率、主频峰值、低频0到500Hz、中频500到2000Hz、高频2000Hz以上能量占比，输出 特征汇总.csv 与 频谱图/。

分类：iterations/v3_分类器.py 按高频能量占比阈值与主频区间做规则判断，异常判为异物/堵塞，正常判为一/二/三档，输出 分类结果.csv 与准确率。

说明：当前为规则验证，不作为通用机器学习模型结论；后续补盲测与抗噪对照。
