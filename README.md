## 02-20Days-Challenge（阶段二 · 项目三）

### 项目三 · 基于手机内置传感器的风扇异常声振诊断仪

**目的**：手机录一段风扇声音(暂时只支持固定风扇)，自动判断是正常、卡了异物还是进风口堵了，不需要任何额外硬件。

### 过程模块化处理

#### 模块一：数据采集与预处理

- 录制 15 条原始样本（一/二/三档、卡入异物、进风口堵住各3次），参数 44100Hz、单声道、距风扇10cm、每段约15秒
- `v1_录音转wav.py`：m4a→wav 批量转码，已加入**防重转逻辑**（目标 wav 存在则跳过），支持增量录音
- 补录 5 段盲测留样（`盲测_`/`盲侧_` 前缀），与训练集物理隔离
- 新增5条带背景噪声样本（`抗噪_` 前缀），噪声源为 B站视频 BV1gM4y1Y7LW
- 采集记录见 `process_logs/采集记录.csv`，标签映射见 `data/label_map.csv`

#### 模块二：特征提取与分类

- `v2_fft特征提取.py`：FFT 频谱分析，提取主频、低/中/高频能量占比，输出 `特征汇总.csv` 及频谱图
- `v3_分类器.py`：基于规则的分类器，对15条原始样本分类正确率 14/15（异物第2次因高频0.248贴近阈值漏判）
- 依据实测数据重构分层判据：主频>100Hz→堵塞 | 主频<95Hz且高频>0.22→异物 | 否则正常

#### 模块三：盲测验证

- `v4_盲测.py`：仅处理 `盲测_` 前缀文件，无答案预测
- `v5_盲测比对.py`：自动比对 `盲测答案.csv` 与 `盲测结果.csv`
- 盲测结果：**5/5 全部正确，准确率 100%**
- 录屏保存至 `reports/盲测录屏.mp4`（已 gitignore）
- 答案封存于 `data/盲测答案.csv`

#### 模块四：抗噪对照实验

- `v2` 升级为增量特征提取，跳过已计算的20条，仅新增10条
- `v6_抗噪分类器.py` 分干净组/抗噪组统计准确率
- 结果：干净样本 20/20 = 100%，抗噪样本 5/5 = 100%
- 说明文档：`process_logs/抗噪说明.md`

#### 模块五：实验报告

- `v7_对比图.py`：生成主频分布与高频占比对比箱线图
- `reports/实验报告.md`：完整实验报告，含摘要、方法、结果、结论、局限
- 汇总采集记录25条、盲测100%、抗噪100% 全部产出

## 局限与改进方向

1. **样本量较小**：当前 25 条，后续可扩充提升泛化性
2. **噪音类型单一**：仅测试了 B站视频一类背景音，后续可加入白噪声、人声、音乐等
3. **未做跨手机验证**：所有录音来自同一部手机，换设备后需重新校准阈值
4. **规则分类有物理上限**：档位之间（如一档 vs 二档）靠当前特征难以区分，后续可引入 MFCC + 随机森林/SVM 作为对比基线
