## 第二阶段：项目三

### 模块一：数据采集与预处理

- 录制 15 条原始样本（一/二/三档、卡入异物、进风口堵住各3次），参数 44100Hz、单声道、距风扇10cm、每段约15秒
- `v1_录音转wav.py`：m4a→wav 批量转码，已加入**防重转逻辑**（目标 wav 存在则跳过），支持增量录音
- 补录 5 段盲测留样（`盲测_`/`盲侧_` 前缀），与训练集物理隔离
- 采集记录见 `process_logs/采集记录.csv`，标签映射见 `data/label_map.csv`

### 模块二：特征提取与分类

- `v2_fft特征提取.py`：FFT 频谱分析，提取主频、低/中/高频能量占比，输出 `特征汇总.csv` 及频谱图
- `v3_分类器.py`：基于规则的分类器，对15条原始样本分类正确率 14/15（异物第2次因高频0.248贴近阈值漏判）
- 依据实测数据重构分层判据：主频>100Hz→堵塞 | 主频<95Hz且高频>0.22→异物 | 否则正常

### 模块三：盲测验证

- `v4_盲测.py`：仅处理 `盲测_` 前缀文件，无答案预测
- `v5_盲测比对.py`：自动比对 `盲测答案.csv` 与 `盲测结果.csv`
- 盲测结果：**5/5 全部正确，准确率 100%**
- 录屏保存至 `reports/盲测录屏.mp4`（已 gitignore）
- 答案封存于 `data/盲测答案.csv`
