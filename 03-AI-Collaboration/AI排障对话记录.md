*   **问题背景**：在配置 Git 安装路径及代码存储路径时，对中文字符的兼容性存在疑问。
*   **排查与结论**：经过 AI 确认，为防止底层编码不匹配导致的寻址失败，**所有路径（文件夹名）必须遵循纯英文、无空格、无特殊符号的原则**。最终将代码工作区设定为 `D:\liujunhao.Github\`。

### 2. 终端路径切换（Bash 语法）
*   **报错现象**：在 Git Bash 环境下执行 `cd /d/D:\Apps___RuanJian\Git`，提示 `No such file or directory`。
*   **原因分析**：Linux/Bash 环境不识别 Windows 的资源管理器路径格式（带盘符和反斜杠）。
*   **解决方案**：改为使用正斜杠，并以 `/d` 代表 D 盘。同时明确代码库不应放在 Git 软件安装目录下，应使用右键 `Open Git Bash here` 在专属工作区直接唤起终端。

### 3. 首次 Commit 报错（身份未配置）
*   **报错现象**：执行 `git commit -m "初始化标准目录结构"` 时，系统提示 `Author identity unknown`，导致后续 `push` 失败。
*   **原因分析**：本地电脑首次使用 Git，未绑定全局 GitHub 账号信息。
*   **解决方案**：通过执行以下命令完成身份绑定，并重新提交：
    ```bash
    git config --global user.email "您的注册邮箱"
    git config --global user.name "您的用户名"

## 三、手机照片批量传输与整理
> **备注**：以下内容切换至千问大模型
### 1. 传输场景与工具选型
* **痛点诉求**：需要快速将手机中的大量截图、水印相机照片无损传输到电脑，避免微信压缩和手动发送的繁琐。
* **敲定方案**：
  * **大批量/无损备份**：使用 **USB 数据线直连**（最快、最稳，保证原图画质和 EXIF 信息）。
  * **小批量/日常拖拽**：使用 **华为多屏协同**（无线连接，在电脑窗口直接拖拽文件）。
* **AI 协同建议**：
  * 传输任务属于“物理数据收集”阶段，建议结合任务 `01-Field-Discovery` 进行记录。

### 2. 手机端关键文件路径定位
在 VS Code 的资源管理器中，通过数据线读取手机文件夹后，目标文件位于以下路径：

| 文件类型 | 相对路径 (从 Pictures 根目录起) | 完整路径 (此电脑 > 手机 > 内部存储 > ...) |
| :--- | :--- | :--- |
| **屏幕截图** | `Screenshots` | `Pictures/Screenshots` |
| **原相机照片** | `DCIM/Camera` | `DCIM/Camera` |

* **注意事项**：
  * 复制时请避开 `.thumbnails` 文件夹，该文件夹内仅包含系统图标缓存，非实际图片。
  * 微信/QQ 的缓存图片通常位于 `Tencent/MicroMsg/WeiXin` 目录下。

### 3. 安全断开连接规范
手机使用 MTP (Media Transfer Protocol) 协议，与 U 盘不同，**不需要在电脑端进行“安全删除硬件”操作**。

* **敲定方案**：
  * **断开前准备**：关闭电脑端所有正在查看手机的资源管理器窗口，确保没有正在传输的文件。
  * **手机端断开（最推荐）**：下拉手机通知栏，点击“正在通过 USB 充电”，将传输模式切换回 **“仅充电”**。
  * **物理拔出**：状态切换为“仅充电”后，直接拔掉 USB 数据线即可，绝对安全。
